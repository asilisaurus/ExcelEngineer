### Шаг 1: Копирование в Google Apps Script

1. Откройте [Google Apps Script](https://script.google.com/)
2. Создайте новый проект
3. Удалите содержимое файла `Code.gs`
4. Скопируйте содержимое `google-apps-script-processor-final.js`
5. Создайте новый файл и назовите его `Testing.gs`
6. Скопируйте содержимое `google-apps-script-testing-final.js`

### Шаг 2: Настройка разрешений

1. Сохраните проект (Ctrl+S)
2. При первом запуске предоставьте разрешения для работы с Google Sheets

### Шаг 3: Использование

**Для обработки данных:**
```javascript
// Основная функция - обрабатывает текущую таблицу
function main() {
  return processGoogleSheets();
}

// Обработка конкретной таблицы
function processSpecificSheet() {
  const spreadsheetId = 'YOUR_SPREADSHEET_ID';
  const sheetName = 'Март 2025'; // опционально
  return processGoogleSheets(spreadsheetId, sheetName);
}
```

**Для тестирования:**
